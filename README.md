# Digital Clock

A live digital clock with date and a 12/24-hour toggle.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/digital-clock.git
```
